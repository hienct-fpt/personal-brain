Use the Personal Brain MCP tools to brief me on this project before we continue.

1. Call `brain_project` with an empty name (current project), or with `$ARGUMENTS` if it looks like a project name.
2. If `$ARGUMENTS` is a topic, also call `brain_search` with it for the current project.
3. Call `brain_recent` with `days: 14` for the current project.

Reply in my language with:

- **Đang làm / Current**: 1–3 bullets
- **Quyết định / Decisions** that affect what we do next
- **Còn mở / Open items**
- **Gần đây / Recent**: last few sessions (date — title)

Keep it under 20 lines. If the MCP server is not available, say so and stop.
